# Python Simple Calculator

## About
A simple calculator built using Python 3 as part of my Python Programming Internship.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- User-friendly menu

## Technology Used
- Python 3

## How to Run
1. Install Python 3.
2. Download `calculator.py`.
3. Open Command Prompt in the file's folder.
4. Run the following command:

`python calculator.py`
